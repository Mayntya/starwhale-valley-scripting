# 技术细节 · Starwhale Valley

README 放「怎么装、怎么玩」，这份放「它是怎么做的」。想改代码之前读这一页。

---

## 它是怎么画出来的

- **全场只有 `fillRect`**，坐标取整到设备像素，所以放到多大的屏都是硬方块，不会有半透明毛边，也不需要任何图片资源（除了角色）。
- **角色是预烘焙贴图**：1536×1872 的精灵表用最近邻缩到 0.375 倍，单帧 72×78，烘成 `whale_day.png`；运行时 1:1 贴，不做任何运行时缩放（大屏按整数倍兜底放大）。
- **夜晚不靠遮罩**：先铺白天表，再按夜色深度用 `globalAlpha` 叠一张被 `lutrgb` 压暗成 0.42 / 0.45 / 0.60 的夜版表 —— 等价于逐像素线性插值，边缘也不会漏出背景色。
- **12 fps 的顿感是故意的**：场景动画的时间被量化成 `floor(t*12)/12`，角色另有 5 / 11 / 7 fps；跑成 60 fps 就变成滑片了。
- **配色是插出来的**：`theme.ts` 里一套 `Palette`（天空五段渐变、云、山、树、草、土、水……二十多个颜色，外加夜色 / 雾浓度等强度），9 个关键帧（0 / 4.2 / 6.4 / 8.6 / 12.5 / 16.6 / 19 / 21.5 / 24 点），`smoothstep` 插值，天气再叠一层 `gradePalette` 调色。
- **世界坐标只有 80 × 170**，画布按 `max(w/80, h/170)` 等比映射，所以点击坐标能一路换算回「她该走到哪里」。

## 声音是怎么算出来的

整套声音**没有一个音频文件**。第一次启动时用纯函数合成（`amb.ts` / `music.ts`），写成 WAV 丢进 App Group 的 `amb-v6/` 缓存，之后直接读盘。

### 环境音：五层循环 + 六个一次性音效

| 图层 | 什么时候响 | 怎么做的 |
|---|---|---|
| 风 | 几乎一直在 | 棕色噪声过三级低通，两层正弦叠出阵风起伏 |
| 鸟 | 白天，晴/阴时最密 | 滑音 chirp + 泛音 + 回声，按簇随机撒 |
| 虫 | 夜里、夏秋最多 | 4.4 kHz 附近的三连脉冲，两条虫错开半拍 |
| 雨 | 雨、雷雨 | 远景雨底（约 650 Hz）+ 300 Hz–1 kHz 的湿润中频带 + 每秒 16 粒闷雨点（700–1600 Hz，30–50 ms 衰）+ 每秒 5 粒近处跳点（响度差四倍）+ 几颗屋檐滴水。**重心不在高频**：高频一片密集小瞬态就成了「下油锅」 |
| 静夜 | 雾、雪、深夜 | 极低通的空气声，慢慢呼吸 |

一次性音效：脚步、水花、鸡叫、木响、树叶沙沙、雷。

混音不是开关，是**连续的权重**：

- **时间** —— 4 点醒来、21 点犯困，白天鸟、夜里虫，天光暗下来它们自动换班
- **天气** —— 雨盖掉鸟、雪让世界安静下去、雷雨风最大；**每一道闪电都配一声雷**：画面和声音共用同一张节拍表 `flashAt()`，平均 9 秒一道（槽位内再随机拖 0–1.6 秒，不走死拍）
- **季节** —— 冬天风更硬、虫声退场、夏夜虫最吵
- **互动** —— 走一步一声脚步（跟腿的摆动同拍），走到池塘溅水、树和草沙沙、鸡咕咕、门和稻草人闷响

声音走 `ambient` 会话：**静音键一拨就静**，也不会打断你在听的东西。切到别的标签、或者点暂停，声音淡下去但引擎不拆，回来立刻有声。

> 想调：`audio.ts` 顶上的 `GAIN`（每层增益）、`MASTER`（三档环境音总音量）、`MUSIC_MASTER`（三档音乐音量）、`SFX_VOL`（每个交互音效）。
> 想删缓存：App Group 里的 `amb-v6/`，删了下次启动会重新算（一两秒）。

### 背景音乐：一首 38.4 秒的循环曲

C 大调、100 BPM、16 小节，A 段 `C–G–Am–F / C–G–F–C`，B 段 `F–C–G–Am / F–G–C–C`。

| 声部 | 音色 | 干什么 |
|---|---|---|
| 主旋律 | 马林巴（正弦 + 3.98 倍木质泛音） | 走五声音阶，动机 `A–G–E` 反复出现，听两遍就能跟着哼 |
| 伴奏 | 拨弦（八分音符分解和弦） | 音量压得很低，只负责「暖」 |
| 低音 | 正弦贝斯 | 每小节根音 + 五度，把地板架住 |
| 垫音 | 慢起慢收的一层气 | 只在 B 段进来，一进 B 段整个人就松下去 |
| 钟琴 | 正弦 + 2.76 倍非谐分音 | A 段和整首收尾各一声「叮」 |

几个刻意的选择：

- **不追求好听，追求「能一直听」** —— 节奏慢、音域窄、没有鼓，旋律只用一个动机反复变奏，适合当背景而不是当主角
- **音量让位给白噪音** —— 曲子整体压得比环境音低一截；三档 `♫ 关 / ♫ 轻 / ♫♫ 响`
- **夜里自动再轻一点** —— 22 点到 6 点曲子会自动降一档，凌晨的农场应该像在打盹
- **接缝听不出来** —— 所有音符的余响超出末尾就取模绕回开头，最后一个小节是主和弦，钟琴的尾巴正好落回第一小节

第一次运行要现算 3 秒左右，所以拆成四段、每段之间让出一帧，不会把画面卡住；算完同样写进缓存目录。采样率用 16 kHz（最高泛音 5.6 k 仍低于 8 k 奈奎斯），省三分之一的运算。

> 想调：`music.ts` 里的 `MUSIC_BPM`（速度）、`PROG`（和声进行）、`MELODY`（旋律）、`MUSIC_GAIN` / `MUSIC_MASTER`（`audio.ts` 里的音量）。

```
├── world.ts                    # 场景绘制：天空/山/农舍/田/树/池塘/雨雪/角色 + 7 个互动点
├── theme.ts                    # 调色板、9 个时段关键帧、插值、天气分级、日月相位
├── season.ts                   # 四季判定、季节配色、萤火虫/流星密度
├── weather.ts                  # WeatherKit 接入 + 10 分钟缓存 + 永不失败的 fallback
├── player.ts                   # 角色状态机：走路、跑动帧、反应/冷却、台词

├── audio.ts                    # AVAudioEngine：懒加载图层、80ms 滑音、WAV 缓存、一次性音效槽位、BGM 独立链
├── hud.tsx                     # 覆盖式控制面板
├── whale_day.png               # 精灵表（待机 6 帧 / 向右 8 / 向左 8 / 挥手 4）
├── whale_night.png             # 同姿势的夜间压暗版
├── LICENSE                     # MIT（不含精灵图与截图）
└── docs/                       # README 用的截图 + 这份文档，不参与打包
```

## 常见问题（完整版）

**Q：为什么首页标签里没有 `✕`？**
因为它是常驻实例，退出键会直接杀掉这个标签的脚本。想换掉就长按标签删除。全屏入口里才有退出。

**Q：天气一直显示「推算天气」？**
说明 WeatherKit 没给到数据：可能是没授权定位、没网，或者系统天气数据拿不到。这时它会按季节 + 时段自己编一个合理的天气，画面不会停。在面板上点天气标签也能手动指定。

**Q：颜色和手机系统时间差很多？**
检查是不是开了 ×60 / ×600，或者之前点过季节标签锁定了季节（标签会变成高亮，不再显示「自动」）。

**Q：开了声音但没声？**
先看面板左下角是不是 `◌ 静音`。真没声的话：检查侧边静音键（`ambient` 会话是跟着系统静音键的）、确认没接着蓝牙耳机断连中的设备。引擎起不来时它只会安静地不响，不会把壁纸弄黑。

**Q：环境音太吵 / 太轻？**
面板上点 `♪` 循环三档。还想细调就改 `audio.ts` 的 `GAIN`（每层，比如 `rain: 0.6` 调到 `0.4`）和 `MASTER`（三档总音量）。

**Q：只想要白噪音，不想要旋律？**
点 `♫` 循环到 `♫ 关`。这时曲子也根本不会去算，不占内存。

**Q：一直挂着会很耗电吗？**
会有一点。它是 24 fps 的 Canvas 连续重绘，纯 `fillRect`，没有图片解码和合成层，但确实一直在算。首页标签切走后会自动暂停；不用的时候点一下 `⏸`。

**Q：这不是要审核上架的 App 吧？**
不是，它是 [Scripting](https://www.scripting.fun) 的脚本，不经过 App Store，改完立刻生效。

## 想自己改

全部是 TypeScript，改完在 Scripting 里重跑就行。

**换配色** — `theme.ts` 的 `KEYS` 是 `[小时, Palette]` 数组，改 `BASE`（正午）、`DUSK`（黄昏）、`DEEP_NIGHT`（深夜）里的颜色，一天的气色就跟着变。想加时段就在 `KEYS` 里插一对。

**加一个互动点** — 三步：

1. `world.ts` 的 `SPOTS` 里加一条 `{ id, x, y, r, line }`，坐标是 80×170 的世界坐标，`line` 可以按季节返回不同台词；
2. `player.ts` 的 `SpotId` 联合类型补上这个 `id`；
3. 想让它「有反应」而不只是弹字，就去 `world.ts` 的 `pulse()` 里给这个 id 加一段动画（摇一下 / 荡一圈 / 抖叶子）。

**换角色精灵图** — 保持表结构一致即可：6 行（待机 6 帧 / 向右跑 8 帧 / 向左跑 8 帧 / 挥手 4 帧），单帧 72×78，脚底基线在帧内第 75 行。夜版用 ffmpeg 直接压暗，别手工涂：

```bash
ffmpeg -i src.png -vf "format=rgba,lutrgb=r=0.42*val:g=0.45*val:b=0.60*val" whale_night.png
```

**调节奏** — `hud.tsx` 的 `SPEEDS` / `SPEED_LABEL` 加倍速档；`farm-view.tsx` 的 `schedule={{ minimumInterval: 1/24 }}` 控制重绘上限。

**自己打包发布** — 用 Scripting 的导出功能生成 `.scripting`（本质是 zip），注意**压缩包内最外层的目录名必须和脚本目录名一致**，否则导入后显示名会变。发布时把附件命名成固定名字（如本仓库的 `Starwhale-Valley.scripting`），导入链接就能永久指向 `releases/latest/download/…`。
